# BoreWise ESP32 Firmware & Hardware Guide

This directory contains the C++ Arduino firmware for the ESP32 bench telemetry module.

## Setup & Flashing Instructions

1. Install [PlatformIO](https://platformio.org/) or [Arduino IDE](https://www.arduino.cc/en/software).
2. Install the `ArduinoJson` library (version 6.x or 7.x).
3. Open `main.cpp`.
4. Update `WIFI_SSID`, `WIFI_PASSWORD`, and `API_ENDPOINT` with your network credentials and AWS Lambda Function URL / API Gateway URL.
5. Select board `ESP32 Dev Module` and flash at 115200 baud rate.

## Bench Testing vs Field Measurement

- **Bench-Tested:** Readings from local desktop/bench test rigs or short test pipes.
- **Field-Measured:** Readings collected from operational deep borewells.

> ⚠️ **Acoustic Ranging Limitation Note:**  
> Ranging in narrow, deep borewells using low-cost acoustic or ultrasonic sensors suffers from signal attenuation, internal pipe reflections, and pump mechanical noise. All telemetry generated by default is labeled as `simulated` or `bench-tested`.
